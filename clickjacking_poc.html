Clickjacking Vulnerability POC

Enter a target URL to test whether it can be framed (i.e., lacks X-Frame-Options / CSP frame-ancestors protection). If the page loads inside the frame below, it is likely vulnerable to clickjacking.

Notes for testers:
- Only test sites you own or are authorized to test.
- If the iframe stays blank or the browser console shows "refused to display in a frame" (X-Frame-Options/CSP: frame-ancestors), the target is protected.
- If content renders, the target is likely vulnerable — consider building a full click-hijack overlay POC to demonstrate impact, and report responsibly.
- Toggle iframe opacity in CSS to simulate the classic "invisible overlay" attack pattern for demonstration purposes.
